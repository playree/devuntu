# 開発者向けドキュメント

Devuntu 自体を開発する人・コントリビュートする人向け。実装の仕組みと、コードからは読み取れない設計上の判断をまとめている。

## はじめに読む

| ページ                                   | 内容                                                                               |
| ---------------------------------------- | ---------------------------------------------------------------------------------- |
| [CONTRIBUTING.md](../../CONTRIBUTING.md) | ブランチ・コミット・PR の出し方、コーディングルール、言語の追加                    |
| [開発](development.md)                   | 開発環境の構築、ビルド、テスト、パッケージ管理、イメージ作成とリリース、紹介サイト |
| [画面一覧とアクセス制御](screens.md)     | 画面・API のパスと、それぞれのアクセス制御                                         |

## 機能ごとの仕組み

| ページ                                                        | 内容                                                                         |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| [AIエージェントの自動運用の仕組み](agent-runner-internals.md) | ランナーの流れ、チケットの状態遷移、承認・差し戻し、タスク分割、利用量の計測 |
| [MCP サーバーの仕組み](mcp-server-internals.md)               | 認証の振り分け、ツールの登録、入力の約束ごと、トークンの保存                 |
| [MCP ツールのリファレンス](mcp-tools.md)                      | ツールの一覧と権限、AI向けコンテキスト・テンプレート、画像の添付 API         |
| [通知の仕組み](notifications-internals.md)                    | 通知キューと配信ワーカー、トリガー、各チャネル、キューの確認、拡張手順       |
| [運用の仕組み](operations-internals.md)                       | バックアップ・リストアとメンテナンスモードの実装、自動メンテナンスの削除条件 |
| [リモート実行の仕組み](command-exec-internals.md)             | 実行の流れ、送るコマンド、実行の記録                                         |

運用者向けの手順(導入・設定・トラブル対応)は [運用者向けドキュメント](../admin/README.md)、
画面の使い方は [利用者向けドキュメント](../guide/README.md) を参照。
機能や仕様を変えた場合は、対応する利用者・運用者向けのページも更新する。
