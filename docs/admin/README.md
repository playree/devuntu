## 導入後にやること

[導入](installation.md)して最初の管理者でサインインできたら、次の順に整える。使わない連携は飛ばしてよい。

1. **ユーザーを追加する** — `/admin/users` で利用者を登録する。部署やチームで分けたい場合は `/admin/groups` でグループを作る
2. **チームボードを作る** — `/boards` の「ボード追加」で作り、ボード設定でメンバー(またはグループ)を割り当てる
3. **連携を有効にする**(任意) — Google・Slack は環境変数を入れたうえで `/admin/settings` から有効にする
   ([環境変数の早見表](environment-variables.md#用途別の早見表))
4. **バックアップを cron に入れる** — `full-backup` を毎日動かし、`backup/` を別の場所へ退避する([定期実行](operations.md#定期実行))
5. **ダッシュボードを整える**(任意) — `/admin/dashboard` でお知らせやリンク、初期レイアウトを設定する
6. **AI を使う**(任意) — 利用者に [AIとの連携](../guide/ai.md) を案内する。エージェントに任せるなら
   `/admin/agents` でエージェントを作り、[ランナーを設置する](agent-runner.md)

アップデートは、メンテナンスモードで利用者を止めてバックアップを取り、止めたまま新しいイメージで起動する
([手順](operations.md#まずはこれだけ))。

## 管理者の画面

`/admin/**` は管理者だけが使える(サイドメニューの「管理者」に出る)。

| 画面                                    | できること                                                                                                                    |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| ユーザー管理(`/admin/users`)            | ユーザーの追加・編集・削除。管理者権限、所属グループ、名前のロック(サインイン時に連携元の名前で上書きしない)を設定する        |
| グループ管理(`/admin/groups`)           | グループの追加・編集・削除。ボードやリモート実行のアサイン、連携の許可グループに使う                                          |
| OIDCクライアント(`/admin/oidc-clients`) | Devuntu でサインインさせる外部アプリの手動登録・編集・削除と、MCP クライアントが自動で登録したもの(動的登録)の無効化・削除    |
| 設定(`/admin/settings`)                 | Googleアカウント連携と Slack 連携の有効化と、利用を許可するグループ(空なら全ユーザー)                                         |
| エージェント管理(`/admin/agents`)       | エージェントの追加・削除、トークンの発行、承認者の設定と、`/agents` と同じ4つのセクション([agent-runner.md](agent-runner.md)) |
| ダッシュボード管理(`/admin/dashboard`)  | お知らせ・リンクの登録と、ダッシュボードの初期レイアウトの編集                                                                |
| リモート管理(`/admin/commands`)         | 定義の読み込み状況の確認と、ターゲットへのアサイン([権限](command-exec.md#権限))                                              |

画面ごとのアクセス制御の実装は [screens.md](../dev/screens.md#管理者)(開発者向け)を参照。
