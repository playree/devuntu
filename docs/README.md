| あなたは                                         | まず読むもの                                | 一覧                          |
| ------------------------------------------------ | ------------------------------------------- | ----------------------------- |
| **使う人**(チケットを書く・見る・AIに任せる)     | [はじめに](guide/getting-started.md)        | [利用者向け](guide/README.md) |
| **立てる人・管理する人**(導入・運用・管理者)     | [導入(セルフホスト)](admin/installation.md) | [運用者向け](admin/README.md) |
| **作る人**(Devuntu 自体の開発・コントリビュート) | [開発](dev/development.md)                  | [開発者向け](dev/README.md)   |
