かんばん形式のボード/チケット管理を中心に、カレンダー連携、メール/Slack/Webプッシュ通知、MCP/AIエージェント連携、リモート実行などを備えたセルフホスト型の開発サーバー構築ツール

A self-hosted development server setup tool centered around Kanban-style board/ticket management.

GitHub でソースを見る Docker Hub

できること

  • かんばんとチケット管理

    ボード、タグ、担当者、優先度、期日、コメント、メンション

  • カレンダー連携

    Googleカレンダー連携と、認証不要な公開URLでの空き時間共有

  • 通知

    メンションや担当者変更をメール / Slack DM / Webプッシュで通知

  • MCPサーバー

    AIエージェントから自分の権限でチケットを操作できる

  • AIエージェントの自動運用

    AIエージェントを担当者として登録し、担当チケットを自動で処理させられる(Claude / Codex に対応)

  • リモート実行

    定義済みの処理をリモートのサーバーで実行し、出力をリアルタイムで確認できる

  • 認証

    パスキー認証、Googleログイン。OAuthプロバイダとしても利用できる

はじめる

Docker Compose で導入できます。手順は導入手順を、機能の詳細はREADMEを参照してください。
