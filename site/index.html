かんばん形式のボード/チケット管理を中心に、カレンダー連携、メール/Slack/Webプッシュ通知、MCP/AIエージェント連携、GitHub/GitLab連携、リモート実行などを備えたセルフホスト型のプロジェクト管理ツール

GitHub でソースを見る Docker Hub

できること

  • かんばんとチケット管理

    ボード、タグ、担当者、優先度、期日、コメント、メンション。親子・関連チケット、受け入れ条件、ボードごとのチケットテンプレート、変更履歴

  • カレンダー連携

    Googleカレンダー連携と、認証不要な公開URLでの空き時間共有

  • 通知

    メンションや担当者変更、エージェントの実行結果をメール / Slack DM / Webプッシュで通知。チームボードは Slack チャンネルへも流せる

  • MCPサーバー

    AIエージェントから自分の権限でチケットを操作できる

  • AIエージェントの自動運用

    AIエージェントを担当者として登録し、担当チケットを自動で処理させられる(Claude / Codex に対応)

  • タスク分割

    大きなチケットはエージェントが子チケットの起票案を出し、承認すると子を順番どおりに自動で処理する

  • AI向けコンテキスト

    対象リポジトリや規約など、ボード共通の前提を MCP クライアント・エージェントへ届ける

  • GitHub / GitLab 連携

    ブランチ・PR・コミットをチケットに紐付けて PR の状態と CI の結果を表示。マージで自動完了、CIの失敗やレビュー指摘でエージェントへ自動で差し戻し

  • リモート実行

    定義済みの処理をリモートのサーバーで実行し、出力をリアルタイムで確認できる

  • 認証

    パスキー認証、Googleログイン。OAuthプロバイダとしても利用できる

  • 日本語 / 英語

    画面の表示言語を切り替えられ、通知の文面も選んだ言語で届く

画面

はじめる

Docker イメージを提供しており、Docker Compose で導入できます。必要なファイルは compose.yaml だけです。

  1. compose.yaml をホストへ配置する
  2. docker compose run --rm tools setup-env で設定ファイルを対話生成する
  3. docker compose up -d --wait で起動する(DBマイグレーションは起動時に自動実行)
  4. /start を開いて最初の管理者を登録する

手順の詳細は導入手順を、機能の全体はREADMEを参照してください。
